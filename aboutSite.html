What is this site about...

SUBWAY TOWER is a story, a world, and a passion project that I made to combine all the ways that I love to experience interactive media. It's meant to be an interactive piece of fiction akin to text-based adventure games, but with a lil modern indie web flair.

It's also just a personal corner of the internet where I can do silly stuff with HTML/CSS/JS and escape from the corporate hell landscape that is the modern internet :P Unless stated otherwise, all art, writing, and code was made by me.

The story of SUBWAY TOWER features themes of unreality, philosophy, and mental struggles, but overall it wasn't really written to take itself seriously. I just like media that tries to break out of its own fictional chains. The site itself tells the story, not just what you see. There are going to be a lot of hidden little elements that you can only find if you really go searching. Of course, you don't need to do all that if you don't want to.

General site info

I have no plans to optimize this site for mobile with the exception of exactly one page (the divination one). Site looks best in Firefox and the only thing I bothered accounting for in other browsers is the scrollbar widths. I tried to account for different desktop screen sizes at least, but I can't guarrantee it will look good on every monitor.

Work in progress forever :3

The concept of the site makes it so that I can kinda keep on adding random shit indefinitely forever, and anything goes. I plan to continue adding stuff for as long as I have ideas (and time lol).

That said, tbh the main reason I made this site is literally just so I can access my oracle deck online anywhere. Most of my updates will probably just be improvements there as I think of features I want.

Site Navigation Tips

Such as how to read this.

This is mostly a reminder to myself of all the bs I did in the site, but also a handy list of things you can try while exploring the site to find all my silly little hidden things. I also understand that some might be less familiar with the ways of Obsessive Website Inspection, so here's a place to start for that too if you ever wanna find out how your favorite webmaster did something.

  • Inspect the code
    • Hit your F12 key (make sure the function [Fn] key is on if you're on laptop) to pull up the site HTML. This is a neat way of checking the raw text for things like the stuff written in the custom font, or even for finding text that's even more hidden.
    • I try not to hide things in a way where inspecting the code is the only way to find them, but I did design the site around the assumption that you could and would do this.
    • (For new devs) This is also how you would debug your site and see why things might not be working as you intended. The Console tab will show you errors, warnings, and anything that you output with [console.log()]
    • You can HOLD [Alt] and click one of the dropdown arrows to uncollapse everything inside a tag.
  • Hover over everything
    • There's a lot of hidden text that can only be seen hy hovering. If you ever see something in the HTML tagged "sneakyText" or "obfuscatedText", that means you can hover over it to see what it says :P
    • There's also things like links that turn into a slightly different color when hovered over.
  • Copy paste the Tower Script text somewhere else
    • One of the main reasons I used a custom font instead of images for the Tower Script is so you could also just highlight it and copy paste it somewhere else to see the raw text.

The Subway Tower Script

I "designed" (if you can even call it that) this when I was like. 14. It was part of a series of one-to-one latin letter scripts that were peculiarly shaped. This one was the "Square" script, and all of these are actually meant to be (and are much more legible when) encased in a square. Unfortunately, I was motivated enough to make a font but apparently not enough to include the actual square. Hence we have this.

I am planning to #eventually make a version with the proper squares, but this font breaks enough font-making standards as is.
